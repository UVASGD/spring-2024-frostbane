# Frostbane


## A Thrilling and Technically Impressive Game Powered by Godot

## Check out the game

[Play the game on itch.io](https://shurininja.itch.io/frostbane)

## Game Description

Immerse yourself in a fast-paced, visually captivating world with horror based mechanics designed to challenge your skills and keep you on the edge of your seat!!

## Tech Stack

- **Godot Engine**
- **GDScript**

With the Godot engine's optimized tools and GDScript's efficiency, we were able to create a game that runs smoothly across multiple platforms while maintaining stunning graphical fidelity.

## Instructions to Play

1. Download and install the game.
2. Launch the game from your preferred platform (Windows, MacOS, Linux).
3. Follow the in-game instructions to start playing and explore the world we've created.
